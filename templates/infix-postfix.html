A QUICK GUIDE

Basic information

Infix places an operator between its operands, while postfix places the operator after them. A stack can preserve the required operation order during conversion. [1]

The two notations

InfixA + B * CEquivalent postfixA B C * +

Postfix expresses the evaluation order without parentheses. This page converts notation; it does not evaluate the expression.

Conversion steps

  1. Send operands to the output.
  2. Keep pending operators on a stack.
  3. Pop operators according to precedence and parentheses.
  4. Move remaining operators to the output.

The stack is LIFO: the latest pushed operator is the first available to pop. [2]

Rules used by this converter

Supported operators: + − * / ^. Exponent ^ has the highest precedence and groups from the right; multiplication/division follow, then addition/subtraction.

For example, A ^ B ^ C becomes A B C ^ ^.

Input and implementation

Enter numbers, variable names, and balanced parentheses within 500 characters. Use (0 - A) for a negative operand.

The Python converter uses linked nodes for its operator stack and output. The displayed snapshots add work beyond the core conversion.
