A QUICK GUIDE

Basic information

These eight programming works let you try text conversion, geometry calculations, data structures, and sorting. Open a tool to use its controls or read its topic guide.

Text and geometry

  • To Uppercase: convert text to capital letters.
  • Area of Triangle: calculate using base and perpendicular height.
  • Area of Circle: calculate using the radius.

Data structures and notation

  • Linked List: insert, delete, and search connected nodes.
  • Queue: explore FIFO operations.
  • Deque: operate at both endpoints.
  • Infix & Postfix: convert expressions using an operator stack.

Sorting

Compare Bubble, Selection, Insertion, Merge, and Quick Sort. Choose ascending or descending order, view the result, and play through the recorded steps.

Each algorithm has its own explanation and complexity summary on the Sorting page.

How to explore

  1. Choose Open on a Works card.
  2. Use the tool with your own input.
  3. Select Basic info & references for definitions, examples, and sources.
  4. Return here using Back to Works.
