    A QUICK GUIDE

    Basic information

    A deque is a double-ended queue, pronounced “deck.” Items can enter and leave at either endpoint. [1]

    Operations

    • Add front / rear: insert at the chosen endpoint.
    • Remove front / rear: remove and return an endpoint item.
    • Peek front / rear: read an endpoint without removing it.
    • Clear: empty the deque.

    Example

    Add rear B → add front A → add rear CFront → A, B, C ← RearRemove rear returns CFront → A, B ← Rear

    For FIFO behavior, add at the rear and remove at the front. For stack behavior, add and remove at the same end.

    Implementation and cost

    This demo uses custom doubly linked nodes. Each node has previous and next links, supporting O(1) endpoint changes.

    Python also provides a built-in collections.deque for efficient operations at both ends. [2] The complete UI request additionally rebuilds and draws the list.

    Input and empty states

    The visual demo allows 12 items, with up to 32 characters each. Duplicate values are allowed.

    Removing or peeking from an empty deque displays an error. Clear empties it, and reloading starts a fresh demo.
