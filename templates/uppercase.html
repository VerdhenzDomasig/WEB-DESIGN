A QUICK GUIDE

Basic information

Uppercase conversion changes letters to their capital forms. This tool uses JavaScript’s toUpperCase() method. [1]

How it works

  1. Enter a word, sentence, or paragraph.
  2. Click Convert to Uppercase.
  3. Read the converted text in the result box.

The method returns a new string; your input remains available for editing.

Example

InputHello, student 01!OutputHELLO, STUDENT 01!

Digits, spaces, and punctuation remain as entered.

Useful for

Creating headings, labels, notices, and consistently capitalized text.

Uppercase conversion changes letter case. It does not translate or rewrite the text.

What this demo accepts

Enter any non-blank text. Unicode casing can expand some letters, such as ß → SS. The method follows Unicode default case conversion. [2]
