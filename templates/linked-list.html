Linked List

⛓

Positions start at 1. Example: insert 20 at position 2 in 10 → 30 to get 10 → 20 → 30.

Result Your list is empty.
A QUICK GUIDE

Basic information

A singly linked list stores values in nodes. Each node links to the next one, forming an ordered chain. [1]

Important terms

  • Node: a value and its next link.
  • Head: the first node.
  • Tail: the last node in this implementation.
  • null: the end of the chain.
  • Traversal: following links from node to node.
[2]

Operations in this demo

  • Insert at Start / End: add at an endpoint.
  • Insert at Position: insert using a 1-based position.
  • Delete Value: remove the first exact match.
  • Search: return the first matching position.
  • Clear: empty the list.

Example and uses

Before10 → 30 → nullInsert 20 at position 210 → 20 → 30 → null

Linked lists can implement queues and stacks. [1]

Cost and input rules

In this implementation, adding at the start or end takes O(1) link operations. Search, deletion by value, and middle insertion can take O(n) traversal work.

Use a non-blank value. With n nodes, insertion positions range from 1 to n + 1. Redrawing the nodes also visits the list.
